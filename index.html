Home

Welcome to the dev build! This is a heavily work-in-progress tool for creating GTFO rundowns, or other datablock-based projects.
I fully expect that you will encounter bugs, errors, and unexpected behaviour.
If something feels not quite right or you have feature suggestions, please send me a message on discord (boston54).

To get started, you can either start a new project from scratch or import an existing project (datablocks).

Starting a New Project

When starting a new project, you can go to the Datablock Editor and click on the +Datablock button on the left panel to build a new datablock. This will prompt you to either use a vanilla datablock as a template, or start a new one from scratch. If you are just learning datablock development, it is recommended to start with a vanilla datablock to familiarise yourself with the structure and functionality of datablocks.

It can also be important to note that many datablocks are designed to work together, and in most cases, datablocks will rely on the data that is present in other datablocks to function properly. Therefore, for the majority of the datablocks, you will want to edit the vanilla datablocks instead of building your own ones from scratch. This is especially important for blocks such as the TextDataBlock which handles the on-screen text that appears throughout the entire game.

Importing a Project

Projects can be imported into the editor by clicking on the Open Project button at the top of the page, and selecting the root folder for your plugin (the folder that contains your datablocks). This will load all of the datablocks, as well as any config files present in the Custom folder.

Modded Datablocks Support

The editor loosely supports modded datablock values from mods such as AdvancedWardenObjective, but more support is planned for the future.

To use object keys that are not present in the vanilla datablocks, you can add your own entries to objects by clicking the Add Object, Add Value, Add List or Add Raw List buttons at the bottom of the object.

To use object values that are not present in the vanilla datablocks, you can select the Custom... option from the dropdown menu and then enter any value.
